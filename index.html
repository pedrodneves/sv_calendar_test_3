About this schedule

Only Approved items from the monday.com board are shown. Colors indicate the network:
  • DevNet — blue
  • TestNet — yellow
  • MainNet — green
Topology Freeze and LSU events are linked: each shows its counterpart and a jump button to the connected date.

Activity Types

Weekly Upgrades
Regularly scheduled Splice version upgrades across networks.
Minimum Splice Versions
Updates to the minimum required Splice validator version for each network.
Minimum Splice Dar versions
Updates to minimum required .dar package versions for each network.
Splice Daml Model Effectivity
Specific versions of Splice Daml models become effective. Nodes that have not upgraded to the Splice version that includes these models may fall out of synchronization.
Protocol Upgrades (LSU)
Logical Synchronizer Upgrade protocol upgrades requiring a topology freeze.
Other Network Configuration Change
Changes to network configuration settings or enabling new features take effect.
